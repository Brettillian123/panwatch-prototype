# Writing a recipe for Sous Vision

Every recipe is one JSON file in this folder, `Recipes/` at the repo root, named `<id>.json`;
beside them sits `sources.json` (credits). These are the sources: people edit them and the
checker checks them, but the app never sees them. What ships is the packed book in
`PanWatch/Core/RecipeBook/`: always 18 files however many recipes there are
(`recipebook-index.json`, `recipebook-sources.json` and `recipebook-shard-00.json` to `-15`,
the full recipes, each in the shard its id hashes to). The packed files are generated by the
commands below and committed with the recipes; never edit them by hand.

## Adding a batch

Write or convert the batch into any folder outside the repo, then run from the repo's top
folder:

```
swift run -c release PanWatchScenarios --add-recipes <folder>
```

It checks every file in `<folder>` with the full checker against the whole book, and refuses
the whole folder if any file fails or an id or title is already in the book, listing each
problem and changing nothing. Otherwise it copies the files into `Recipes/`, adds a credit to
`sources.json` for any outside source the book lacked (from the recipes' `source` fields:
"Recipes adapted from <name>." and the site's address; edit the line if the source asks for
other words, then run `--check-recipes --pack`), rewrites the packed files and prints a
summary: added, total, and per category. Commit `Recipes/` and `PanWatch/Core/RecipeBook/`
together.

A recipe a converter held aside may carry a top-level `"_held"` note (why it was held). The
checker skips that field, and `--add-recipes` drops it: the copy in `Recipes/` never has it.
Files without one are copied byte for byte.

## Checking

```
swift run -c release PanWatchScenarios --check-recipes
swift run -c release PanWatchScenarios --check-recipes --pack
swift run -c release PanWatchScenarios --check-recipes <folder> [--only pad-thai,fish-tacos]
```

The first checks the whole book and that the packed files match `Recipes/` exactly (after
any hand edit to a recipe it reports them out of date, and so does `swift test`). The second
does the same after repacking when the sources pass. The third checks a folder of recipe
files as a book of its own, or just the slugs given. Each prints one line per problem,
starting with the file's name, then a summary: files, passed, failed, and the failures
counted by rule. It exits 1 on any problem. A recipe is done only when the checker prints no
problems for it.

## Who reads it

A home cook with the phone propped on the counter, hands busy. The screen shows each step's
`instruction` in big type, three lines at most; the app reads `spoken` (or the instruction)
aloud. Write the way a friend standing beside them would talk: short, plain, one thing at a
time. No jargon, no brand names, no claims that food is done.

## A full example

`garlic-butter-pasta.json`:

```json
{
  "id": "garlic-butter-pasta",
  "title": "Garlic Butter Pasta",
  "category": "Pasta and grains",
  "method": "pot",
  "source": { "name": "Sous Vision" },
  "serves": 4,
  "totalMinutes": 20,
  "ingredients": [
    { "amount": "1 pound", "name": "pasta" },
    { "amount": "1 tablespoon", "name": "salt" },
    { "amount": "3 tablespoons", "name": "butter" },
    { "amount": "4 cloves", "name": "garlic, minced" }
  ],
  "steps": [
    { "instruction": "Bring 4 quarts of water and 1 tablespoon of salt to a boil." },
    {
      "instruction": "Add 1 pound of pasta to the boiling water.",
      "watch": { "ingredient": "pasta", "timerLabel": "Pasta", "timerMinutes": 9, "minimumChange": 0.02, "countsRelease": true }
    },
    {
      "instruction": "Melt 3 tablespoons of butter in a pan over medium heat.",
      "cue": { "timerLabel": "Pasta", "secondsLeft": 180 }
    },
    {
      "instruction": "Add 4 cloves of minced garlic to the butter.",
      "watch": { "ingredient": "garlic", "timerLabel": "Garlic", "timerMinutes": 1, "minimumChange": 0 },
      "cue": { "timerLabel": "Pasta", "secondsLeft": 90 }
    },
    {
      "instruction": "Drain the pasta and toss it in the garlic butter.",
      "cue": { "timerLabel": "Pasta", "secondsLeft": 0 }
    }
  ]
}
```

What happens in the kitchen: the cook boils water; when the pasta goes in, the camera sees it
and offers a 9-minute timer; with 3 minutes left the app calls out the butter step, with 90
seconds left the garlic, and when the timer ends, the draining.

## The fields

### Top level (all required)

| Field | What it is | Rules |
|---|---|---|
| `id` | The slug: the title in lowercase words joined by hyphens, `"hard-boiled-eggs"`. Never changes once shipped. The dish photo is the asset `dish-<id>`. | Lowercase letters, digits and single hyphens. The file is named `<id>.json`. Unique in the book. |
| `title` | The dish's name, in title case: `"Garlic Butter Pasta"`, `"Chicken with Rice"`, `"Hard-Boiled Eggs"`. Screens show it in sentence case ("Garlic butter pasta") on their own. | Every word capitalized, including after a hyphen, except `a an and as at by for in of on or the to with de la le el con al à au di da` after the first word ("Dulce de Leche"). At most 48 characters, no period. A short English gloss in parentheses may follow a foreign name and keeps its own case: `"Risengrød (rice porridge)"`. Unique in the book. Make the words distinctive: the cook picks a dish by voice from them ("make the lentil soup"). |
| `category` | Its shelf on Home. | Exactly one of: `"Pasta and grains"`, `"Eggs and breakfast"`, `"Vegetables"`, `"Salads"`, `"Chicken"`, `"Beef and pork"`, `"Fish"`, `"Soups"`, `"Beans and lentils"`, `"Sandwiches and wraps"`, `"Snacks and sides"`, `"Sauces and dips"`, `"Baking and desserts"`, `"Drinks"`. |
| `method` | The main way it's cooked. | One of `"pot"` (boil, simmer, steam on the stove), `"pan"` (sear, fry, sauté on the stove), `"oven"`, `"noHeat"`. Only `pot` and `pan` recipes may use the camera (`watch`); the list's "Stovetop" filter shows those. |
| `source` | Where the recipe comes from, for the credits on Profile > Advanced > About (never shown on the recipe). | `{ "name": "Sous Vision" }` for the app's own. Otherwise `{ "name": "Serious Eats", "url": "https://..." }`; the url must start `https://`, and the name must have its entry in `sources.json` (below). Optional `"credit"`: the program or author the source credits for this recipe (`"credit": "Healthy Kitchen Program"`), listed once under the source on About, never on the recipe. |
| `serves` | How many people the amounts feed. Optional: leave it out when the source doesn't say; the screens then show the time alone. | 1 to 100 when present. |
| `totalMinutes` | Start to plate, including waits (boiling water, resting, rising). | 1 to 1,440, and at least the sum of every timer in the steps. 20 or less puts it in "Quick ones". Screens show "25 min", "1 hr 30 min", "8 hr". |
| `ingredients` | What to gather, in the order used. | At least one. See below. |
| `steps` | The steps, in order. Steps are numbered by their place; don't number them. | 3 to 20. See below. |

### An ingredient

`{ "amount": "1 cup", "name": "long-grain white rice" }`

- `amount`: a number (`"4"`, `"1/2"`, `"1 1/2"`, `"2-3"`, `"14.5"`), `"a"`/`"an"`, or `"a few"`/`"a
  couple of"` with a unit, then optionally a size (`large`, `medium`, `small`, `heaping`...),
  then optionally a US kitchen unit or count: cup, tablespoon, teaspoon, pound, ounce, fluid
  ounce, quart, pint, gallon, clove, pinch, dash, cube, can, jar, bottle, packet, envelope,
  package, bag, box, stick, slice, piece, strip, wedge, sheet, drop, bunch, head, sprig, stalk,
  leaf, loaf, ear, handful, fillet, breast, thigh, rib, link, inch, bowl, square, block, scoop,
  spray, splash, knob, bulb, rack, tin, carton, tub, pouch, bar, round (plurals fine).
  `"to taste"` and `"as needed"` are allowed. No grams, milliliters or Celsius. Words like "minced" go in the
  name, not the amount.
- `name`: lowercase unless a proper noun; extra detail after a comma (`"garlic, minced"`).
- It is read aloud as `"1 cup of long-grain white rice"` when the amount ends in a unit, else
  `"4 eggs"`, `"1 large onion"`; `"salt, to taste"`.
- Every ingredient must be named in some step: its main name (before the first comma, any
  parentheses taken out), or the last word of it ("long-grain white rice" is used by "the
  rice"; "tomatoes (canned), drained" by "the tomatoes"; plurals forgiven).

### A step

| Field | Required | What it is |
|---|---|---|
| `instruction` | yes | What the screen shows. One action, ending with a period, at most 90 characters (three lines in cook mode). A second sentence may say what to look for ("Cook the onions until soft. The edges should be golden." is fine); two sentences that each start with a command ("Boil the water. Add the salt.") are two steps. Keep every number the cook needs (amounts, minutes, °F). |
| `spoken` | no | What is read aloud when it should say more than the screen: "Flip the chicken and cook about 6 more minutes, until a thermometer reads 165 °F in the thickest part." Leave it out when the instruction says it all. May be several sentences. |
| `watch` | no | The camera watches for something going into the pot or pan and offers a timer. Pot and pan recipes only. |
| `cue` | no | Call this step out on its own when an earlier step's timer has this much left. |
| `timer` | no | A plain timer the step names with no camera: `{ "label": "Bake", "minutes": 25 }`, whole minutes, 1 to 480. Use it for oven and no-heat recipes, any stovetop time with nothing being added, and waits off the heat ("Let it rest for 5 minutes."). A step has a `watch` or a `timer`, not both. When the step opens, cook mode offers it on the card: "This step takes 25 minutes." / "Start a 25-minute timer?"; it starts only on a tap or "yes". |

#### `watch`

`{ "ingredient": "pasta", "timerLabel": "Pasta", "timerMinutes": 9, "minimumChange": 0.02, "countsRelease": true }`

- Only on a step that adds something to a pot or pan on the stove: the instruction starts with
  Add, Stir in, Lower, Lay, Drop, Put, Pour, Place, Slide, Crack, Tip, Spoon, Scatter,
  Sprinkle, Toss in, Set or Return, optionally after an adverb ("Gently add", "Slowly pour").
- `ingredient`: spoken in the offer, "Looks like the pasta went in." Lowercase.
- `timerLabel`: the timer's name, one or two words, capitalized: "Pasta". Unique in the recipe.
- `timerMinutes`: whole minutes, 1 to 480. Past 99 the offer says hours: "Start a 6-hour timer?"
- `minimumChange` (optional): how much of the pan must change, 0 to 1. Use `0` for things
  too small or that sink out of sight from a phone on the counter (minced garlic, rice, oats,
  eggs on a spoon): a hand visiting the pot is then enough. Use `0.02` for things you can see
  (pasta sticking out, broccoli, chicken in a low pan). Leave it out for the usual setting.
- `countsRelease` (optional, default false): `true` for food carried in the hand and let go
  over the pot (a handful of pasta, florets, chicken pieces).

#### `cue`

`{ "timerLabel": "Pasta", "secondsLeft": 180 }`

- `timerLabel` names a timer started in an earlier step, `watch` or plain `timer`.
- `secondsLeft`: 0 means when that timer ends; never more than the timer runs.
- Use it so the parts finish together (start the sauce 3 minutes before the pasta is done).

## Wording rules the checker enforces

1. **Times have timers.** Any cooking time in a step ("simmer 10 minutes", "bake for 25
   minutes", "1 hour") must equal a timer in the recipe (`watch.timerMinutes` or
   `timer.minutes`). A range ("7 to 10 minutes", "6-8 hours") needs a timer on either number;
   use the lower ("3 to 4 hours" takes a 180-minute timer). Waits off the heat (rest, sit,
   stand, cool, chill, soak, ice water) need their timer too, on the step that names them.
   Times of a minute or less, in seconds or fractions ("30 seconds", "60 seconds", "90
   seconds", "1 1/2 minutes"), need no timer, nor does an interval ("stir every 15 minutes").
2. **No step is only a wait.** "Wait 10 minutes." alone is not a step; put the time on the
   step that starts it. A rest or cool after cooking with its own `timer` is a step: "Let it
   cool in the pan for 10 minutes."
3. **Plain words.** None of: model, engine, sample, calibrate, exposure, flicker, frame,
   detection, debug, session, AI, MB, GB, ms and the rest of `PlainWords.banned`.
4. **No brand names.** "hot sauce", not a brand; "slow cooker", not a brand; "plastic wrap".
5. **The app never says food is done, safe, ready or at a temperature.** Say what to look for:
   "until the onions are soft", "until the edges are golden". Not "the chicken is done".
6. **Temperatures are °F** (digits, "350 °F" or "350 degrees"), and only as something the
   cook sets ("Bake at 350 °F.", "Preheat the oven to 425 °F.", "Heat the grill to 350 °F.",
   "Cook the syrup to 270 °F.", "in a 350 °F oven", "110 to 115 °F water", "between 325 and
   350 °F") or measures, for any food: "until a thermometer reads 165 °F", "until it reaches
   about 185 °F" (for meat, use the food safety table: 165 °F poultry and leftovers, 160 °F
   ground meat, 145 °F fish and whole cuts of beef, pork and lamb, rest 3 minutes). Never
   that the food is at one ("the chicken is now 165 °F"); "ready to flip" is a cue, not a claim.
7. **The screen and `spoken` agree on every number.** Every number in `instruction` is in
   `spoken` with the same value, as digits or words ("1/2" or "half", "1 1/2" or "one and a
   half"). `spoken` may add a number only when it is a range's upper end whose lower end is on
   screen ("Cook 3 minutes." / "Cook 3 to 4 minutes."), a temperature or size to measure or
   look for ("until a thermometer reads 165 °F", "a 12-inch circle"), the step's own timer, a
   count or fact ("makes 20 servings"), or an amount already shown in an earlier step or the
   ingredients. A time, an oven or pan setting, or a new amount only in `spoken` fails, and so
   does a number on screen that `spoken` drops or changes: "The screen says 2 cups but the
   spoken text says 3 cups; make them match."
8. **No unknown fields.** A typo like `"spokn"` is reported, not ignored.

## Sources and credits

Profile > Advanced > About lists each outside source once, with its credit line and link,
from `sources.json` (shipped as `recipebook-sources.json`). The first recipe from a new
source adds its entry (`--add-recipes` writes a plain one):

```json
[
  { "name": "Serious Eats", "credit": "Recipes adapted from Serious Eats.", "url": "https://www.seriouseats.com" }
]
```

`name` matches the recipes' `source.name` exactly. The checker reports a source with no entry.

## Checklist for a new recipe

- [ ] `id` matches the file name; `title` is title case and distinctive.
- [ ] Category and method from the lists above.
- [ ] Every ingredient has a US amount and appears in a step.
- [ ] 3 to 20 steps, each one action, at most 90 characters.
- [ ] Pot or pan: the step where the main ingredient goes in has a `watch` with its timer.
- [ ] Oven or no-heat: timed steps have a `timer`, never a `watch`.
- [ ] `totalMinutes` covers every timer plus the waits.
- [ ] `--check-recipes <your folder>` prints no problems; then `--add-recipes <your folder>`, and commit `Recipes/` with `PanWatch/Core/RecipeBook/`.
- [ ] An outside source has its entry in `sources.json` (`--add-recipes` adds a plain one).
- [ ] A photo can come later: without `dish-<id>` the app shows a plain tile with the category's symbol.
